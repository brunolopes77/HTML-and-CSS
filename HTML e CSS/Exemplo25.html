Exemplo 25 HTML CSS - Formas de vinculação de arquivos CSS

Existem 2 formas básicas de vinculação de arquivos css em documentos html, essas formas são a interna e a externa. Neste Exemplo vamos demonstrar a vinculação externa, que é aquela onde criamos ou utilizamos um arquivo .CSS externo.

A vinculação externa apresenta uma série de vantagens em relação a vinculação interna de arquivos .CSS dentre as vantagens podemos citar:

  • Facilidade de Manutenção: Isso ocorre, pois você edita apenas um arquivo CSS que é aplicado a todos os arquivos que o utilizarem.
  • Reutilização de Código: um único código ou arquivo de estilo pode ser ligado a dezenas ou centenasde páginas HTML.
  • Carregamento mais rápido: o navegador guarda em cache o arquivo CSS carregado, o qu e aumenta a velocidade de carregamento da página HTML.
  • Organização de código: Quando utilizammos arquivos CSS externo, ele fica separado do arquivo HTML, o que facilita a análise, organização e manutenção destes arquivos.

Vinculação Externa

A vinculação externa é a forma mais recomendada, neste caso o CSS é um arquivo a parte que pode ser criado pelo desenvolvedor ou um arquivo de um grupo, como exemplo o FrameWork Bootstrap. Neste caso, para vincular o arquivo externos devemos usar a tag link.

Neste exemplo, estamos usando uma arquivo externo para estilizar todos os nosso elementos. Ou seja, nesse arquivo externo temos nossas regras de estilização que serão aplicadas a este documento ou qualquer outro. É importante frisar que a vinculação externa é a mais recomendada pois facilita a manutenção e o reuso do arquivo.
