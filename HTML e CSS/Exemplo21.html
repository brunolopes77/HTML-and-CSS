Seletores de Classe

O seletores de classe em css, são identificados por um ponto seguido do nome do seletor. Esse seletor é muito versatil pois pode ser compartilhado com vários elementos html. Para utilizá-lo devemos usar o atributo Class no componente html. Neste exemplo estamos aplicando o seletor classe no documento.
